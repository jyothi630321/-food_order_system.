# 🍽️ Restaurant Food Ordering System

A simple console-based Restaurant Food Ordering System developed using Python. This project allows users to view the menu, add and remove food items from the cart, select quantities, and generate the final bill.

## Features

* View food menu
* Add items to cart
* Remove items from cart
* Select quantity
* View cart
* Generate bill

## Technologies Used

* Python 3

## How to Run

```bash
python food_order_system.py
```
